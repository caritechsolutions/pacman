## 支持的视频解码功能

| 视频标准    | 支持的级别和等级                                |
| ----------- | ------------------------------------------------|
| MPEG2       | MP @ HL                                         |
| MPEG4       | SP and ASP @L5, not support GMC/MP42            |
| AVS         | AVS jizhun Profile                              |
| AVS+        | AVS Broadcasting Profile                        |
| RMVB        | RV8 RV9 RV10                                    |
| Divx        | Divx From Ver3.x to Ver6.x, Support as MPEG4    |
| H264        | Main Profile and High Level@level4.1            |
| H265        | Main Profile and High Level@level4.0            |
| H265 Main10 | Main10 Profile and High Level@level4.1          |
