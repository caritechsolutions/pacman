# 功能概述

- [模块初始化](init.md)后，使用一个功能的流程：
  1. **配置**
     - **配置**是指在功能**启动之前**，可以(需要)做的事情；
     - 通常，为了满足需求的多样性，一个功能会有多种配置；
     - 配置分必选和可选两种情况；
     - 如无特殊说明，这些配置无先后顺序；
  2.  **启动**
     - 调用一个或多个接口实现功能的**启动**；
  3.  **控制**
     - 控制是指功能**启动之后**，可以做的事情；
