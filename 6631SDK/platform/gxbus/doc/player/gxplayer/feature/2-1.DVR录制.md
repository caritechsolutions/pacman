## DVR录制

### 概述
- 节目数据来源于DVB,以分卷协议(DVR)方式File储存.
- 录制来源协议: "dvbs://","dvbs2://","dvbt://","dvbt2://"等等.
- 录制文件后缀: ".dvr".

### 功能
#### 注册
- \ref GxPlayer_ModuleRegisterStreamDVB
- \ref GxPlayer_ModuleRegisterDemuxerHWTS
- \ref GxPlayer_ModuleRegisterRecorderDVB
- \ref GxPlayer_ModuleRegisterStreamFILE
- \ref GxPVRPlayer_RegisterEncrypt
- \ref GxPVRPlayer_UnRegisterEncrypt
#### 配置
- gxloader配置
	- gxloader CMDLINE_VALUE 下 "tswmem"字段配置.
		- 安全录制,用户需要处理安全加密时,例如:vmx+方案,必须配置该字段.
		- 非安全录制,不需要配置该字段.
- 系统配置:
	- \ref PLAYER_CONFIG_RECORD_CACHED_MEMSIZE
	- \ref PLAYER_CONFIG_RECORD_TSW_MEMSIZE

#### 场景六.DVR用户加密
- ![示例](2-4.示例代码.md#DVB录制-用户加密和非用户加密-示例代码)
- 注意事项:
	- 用户加密方式录制可用于安全录制和非安全录制模式下录制.
	- 用户加密方式下,不同读取数据方式的加密参数区别,用户只需要关心加密回调参数的:
		- 非安全录制
		- 安全录制下,gxloader未配置tswmem字段:
			- 输入buf和输出buf都非保护,cpu可以正常读写.
			- ibuf_type( \ref PlayerPvrEncryptPara ) = PLAYER_PVR_BUF_NORMAL.
			- ibuf_type( \ref PlayerPvrEncryptPara ) = PLAYER_PVR_BUF_NORMAL.
		- 安全录制下,gxloader配置tswmem字段:
			- 输入buf受保护,cpu无法读取数据.输出buf非保护,cpu可以正常读写.
			- ibuf_type( \ref PlayerPvrEncryptPara ) = PLAYER_PVR_BUF_SECURE.
			- obuf_type( \ref PlayerPvrEncryptPara ) = PLAYER_PVR_BUF_NORMAL.
